## Which file do I need?

| File | For |
| --- | --- |
| `SparkyPDF-Setup.exe` | **Most people.** Installer for any 64-bit Windows 10 or 11 PC, ARM or not. Installs for your account only, adds a Start menu entry and can be removed again from Windows Settings. |
| `SparkyPDF-arm64.exe` | Portable program for Windows on ARM. No installation: put it anywhere and start it. |
| `SparkyPDF-x64.exe` | Portable program for ordinary 64-bit PCs. |
| `SHA256SUMS.txt` | Checksums of the files above. |

Sparky PDF needs the WebView2 Runtime, which Windows 11 already includes.

The files are not code-signed, so Windows may show "Windows protected your PC" the first time. Choose **More info**, then **Run anyway**.
